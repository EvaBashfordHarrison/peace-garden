# The Peace Garden

## Description
This web app is an assessment of a country's peace based on a calculation of its population that isn't ready for war. Use the click-through to select a country, and visualise through the growing garden the vastness of peace that a countries population holds. 

## Concept
There are currently 86 armed conflicts around the world (reference: https://warwatch.ch/explore/) - equating to 44% globally. 
To steer away from reporting war, this web app reports peace. Taking a public database of military data per country (reference: Abhijit Dahatonde, https://www.kaggle.com/datasets/abhijitdahatonde/global-armed-forces-dataset?resource=download), and working out the non-active total number of military per 1000 capita, to create a scale of peace over each country. 
The user clicks on a country, and is shown a garden blooming based on how many people aren’t conscripted or trained for war. If a country has a small army, they are more prepared for peace than war. 
Let’s take the data; clicking through to Guinea, they have an army of 1 per 1000 capita, meaning their peace value is 99.99%, generating 99 flowers. In contrast, North Korea has an army of 300 per 1000 capita, meaning their garden only grows 70 flowers. 
There’s more to a country than the wars it’s in, and often, from the media alone, perceptions of civilians in a country can be based on conflict alone. This project illuminates the peace within the people in every country around the world. 

## Dataset and Credits
The dataset was sourced from "Global Armed Forces Dataset" by Abhijit Dahatonde, available from Kaggle (https://www.kaggle.com/datasets/abhijitdahatonde/global-armed-forces-dataset?resource=download)  

## How to run
Please open the webpage and when prompted, select a Country from the list. Then watch a stunning garden grow.
